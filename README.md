# Studio Célia Fróes

Protótipo de site institucional para o Studio Célia Fróes, no Pilarzinho.

## Visualização

Depois de ativar o GitHub Pages:

`https://guilhermebattiston.github.io/celia-froes-pilates-prototipo/`

## Publicação

1. Abra **Settings → Pages**.
2. Em **Source**, selecione **GitHub Actions**.
3. Acompanhe o fluxo “Publicar no GitHub Pages” na aba **Actions**.

Novos envios para a branch `main` serão publicados automaticamente.

> Protótipo não oficial. As informações devem ser confirmadas com a empresa.
